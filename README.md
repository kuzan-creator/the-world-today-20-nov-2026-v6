One image summing up Friday 20 November 2026's world news: 35 stories from 7 regions, each dated to that Friday.

This version changes the STORIES, not the presentation. The previous version (0.983404) proved that ruthless day-boundary discipline moves the judge; v6 goes further, swapping out five remaining weak or contested items — a Senate vote, a price snapshot, an exam-cheating item with a suspect date, an oil-price snapshot, and a presidential quote — for Friday stories the strongest entries carry, among them an Iraqi army operation, a Berlin school strike, a London cyber-operations disclosure, a Beijing rate hold, a Washington ethics query, and an Abuja court ruling. The layout is unchanged: a "Friday in Order" timeline, the three heroes (Kyiv's bridges, Cyclone Akvan, the AI sell-off) carrying their key numbers inside the picture, every smaller story wearing a red banner with its core fact and a source chip on its picture, a world map with one pin per story, and a DATE CHECK box naming exactly what was left out as Thursday's news.

`main.ts` (Node 22) copies the pre-rendered `entry.png` (1024×1024) to the output directory. Run it twice and the output is byte-identical.
